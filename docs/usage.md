# 使用说明

启动后点击“导入日志”，可一次选择多份文件。顶部下拉框切换报告，各报告独立保存。

**报告管理**：按文件名、服务器 SN、GPU SN / UUID 搜索，筛选和排序报告。勾选两份可直接对比。支持多选重新解析，缺少原日志时重新选择文件；文件内容须与原报告一致。每份成功后更新原报告，失败或取消保留旧结果；取消后停止后续处理。

**设备信息**：查看服务器 SN 与所有 GPU，按 SN / UUID / PCI 地址搜索。“查看来源”保留原始行；“复制到 Excel”使用制表符分列。

**错误记录**：默认按设备和类型聚合，显示记录条数及首末记录。点击“查看原始记录”展开该组，100 行一页。时间含完整日期和时区时按时间排列，否则按日志顺序排列。记录条数不等于独立故障次数。

**日志对比**：顶部选择当前报告，再在“日志对比”中选择基准报告。仅按双方唯一且无冲突的 SN / UUID 匹配，PCI 地址和槽位不作为配对依据。未匹配项分别保留，不视为已新增或移除设备；“系统记录”显示未关联 GPU 的错误。错误条数按各报告统计，时间范围可能不同。点击字段可并排查看两份原文及行号；缺失字段和多个采集值不计为变化。

**状态解析与异常检查**：按 GPU 和采集块查看 nvidia-smi -q 参数；在检查矩阵中选择异常、待核实或数据不足项，查看判断依据与原文。

**机器拓扑**：查看 PCIe 连接树和 GPU / NIC 互联矩阵。连接只采用可唯一关联的桥或 sysfs 证据。字段含义、采集命令和判断范围见[状态与拓扑](diagnostics.md)。

**槽位参考**：lspci Physical Slot 与 dmidecode Type 9 Bus Address 匹配结果分别保留。模组机或复杂底板仍需结合 SN 和设备标签定位。

**解析规则**：导入 Xid 表格（XLSX）或规则 JSON，查看规则及官方文档。新规则用于新导入或重新解析的报告；导入的规则可查看来源详情。

**导出**：设备清单为 TSV，Excel 可打开；日志摘要为 TXT；完整证据为 JSON。

关闭窗口结束程序。结果保存在 `runtime/results`，原日志副本保存在 `runtime/sources`。在“报告管理”中删除报告时，会清理不再使用的副本，原始文件不受影响。

升级时先退出软件，用新版 `XidLens.exe` 替换原文件，保留同目录的 `runtime` 文件夹。

单次上传最多 512 MiB。压缩输入的成员、总读取量和事件数有限额，超限会提示读取不完整。

**在线更新**：默认每天在后台检查软件版本，检查失败不弹窗；已有的关闭设置会保留。发现新版后可下载更新、暂不更新（延后一天）或不再提醒此版本。检查与提醒可在“软件更新”中分别关闭。下载完成后点击“重启并更新”，保留报告与规则。

**官方规则**：在“解析规则”检查 NVIDIA 官方英文表，确认后替换当前规则。已有报告不变，重新解析后使用新规则。

**Xid 查询与排查手册**：搜索中文 Xid 说明或按问题查看排查步骤。各页的“版本与更新”显示当前版本与来源，可单独检查和更新资料；失败或取消保留原内容。
