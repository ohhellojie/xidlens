# 使用说明

启动后点击导入日志，可一次选择多份文件。顶部下拉框切换报告，各报告独立保存。

**诊断概览**：按状态筛选或搜索重点发现，选择一项查看依据、证据和下一步。字段冲突保留各来源；未见异常仅覆盖已检查项目。缺失项提供补采命令，需自行在目标机器读取并保存输出。

未导入日志时，可点击查看示例加载合成日志，或查看采集说明。

**报告管理**：按文件名、服务器 SN、GPU SN 或 UUID 搜索，筛选和排序报告。勾选两份报告可直接对比。支持多选重新解析；缺少原日志时，选择与原报告内容一致的文件。

**联合分析**：在报告管理中选择同次采集的 2 至 32 份报告，点击联合分析建立关联。各报告独立保留，设备仅按唯一且一致的 UUID 或 SN 匹配；身份冲突时分别展示。每条事件和检查结果保留来源文件及原始行号。

来源重新解析后，关联页会提示变化，点击刷新成员采用新版结果。缺失来源不计入当前分析，内容相同的文件仅计一次。移除关联保留来源报告。

重新解析逐份保存成功结果，失败或取消的报告保留旧结果。取消操作同时结束后续队列。

**设备信息**：查看服务器 SN 与 GPU 清单，按 SN、UUID 或 PCI 地址搜索。点击查看来源可追溯日志原文，复制到 Excel 后按列展示。

**错误记录**：按设备和类型分组，按日志条目计数，并显示首末记录。点击查看原始记录展开该组，每页 100 行。含完整日期和时区的记录按时间排列，其余按日志顺序排列。

**事件时间线**：查看错误、驱动加载、明确的重置结果和 GPU 状态快照，按设备、类型、时间范围或文字筛选。分组保留成员记录及原文入口；联合分析中可查看多份来源的时间线。

时间线按来源、启动标识及启动后时间回退分段。段内记录均有完整日期和时区时按时间排序，其余保留原文顺序。启动后秒数仅在各来源分段内核对。Xid 154 的恢复动作变化保留原值；动作变为 None 时显示动作变化，健康状态仍需独立核验。

**日志对比**：在顶部选择当前报告，再进入日志对比选择基准报告。GPU 配对要求 SN 或 UUID 在两份报告中唯一且无冲突。未匹配设备分别列出，并显示原因；系统记录汇总未关联 GPU 的错误。

字段变化按双方均有单一采集值的字段统计，缺失和多值字段分别标记。计数字段核对身份、时间顺序、volatile 或 aggregate 范围、计数周期及重置证据；条件不足时保留两侧值和不可比原因。常规日志缺少已验证的计数周期时，仅展示采集值。错误数量按各报告的日志范围统计。

点击字段可并排查看两份原文及行号，原文入口支持跳转到基准或当前报告，返回后保留对比对象。

**状态解析与异常检查**：按 GPU 和采集块查看 `nvidia-smi -q` 参数。在检查矩阵中选择项目，查看判断依据与原文。

**完整日志**：阅读原始内容，支持全文搜索、行号跳转、自动换行与专注阅读。右侧滚动条标出搜索结果和异常位置。分析页面的原文入口可直接跳到对应行，并返回原页面。

点击行号后按住 Shift 选择另一行，或用 Shift 和上下键扩展范围。点击添加片段进入证据与分享，填写标题、备注和标签后保存。每个片段最多 200 行。

**证据与分享**：书签保存在本机，不修改原日志。每次选择最多 100 个书签，设置脱敏字段及其他需隐藏的文字，生成预览。主机名、序列号、UUID、IP 地址和路径默认脱敏；同一报告中的同一值使用一致化名，备注和标签一并处理。

核对预览中的来源名、片段和备注，可直接编辑内容。勾选已检查本次导出的内容后下载 TXT 或 JSON。自动脱敏可能遗漏自由文本中的信息，修改选项或内容后需要重新检查。原文内容变化时，旧书签标记失效并停止导出；同内容重新解析可保留书签和化名。

切换页面或日志会保留各报告的阅读位置和筛选条件。阅读位置、搜索词和换行设置会在重启后恢复。旧报告缺少原日志副本时，需要重新导入原文件。

**机器拓扑**：查看 PCIe 连接树，以及 GPU 和网卡的互联矩阵。设备连接由可唯一关联的 PCIe 桥或 sysfs 路径确定。字段含义、采集命令和判断范围见[状态与拓扑](diagnostics.md)。

**槽位参考**：分别显示 lspci Physical Slot 与 dmidecode Type 9 Bus Address 的匹配结果。使用 SN 和设备标签核对物理位置，尤其是模组机和复杂底板。

**解析规则**：导入 Xid 表格（XLSX）或规则 JSON，查看规则及官方文档。新规则用于新导入或重新解析的报告；导入的规则可查看来源详情。

**导出**：设备清单为 TSV，Excel 可打开；日志摘要为 TXT；完整记录为 JSON。

关闭窗口结束程序。结果保存在 `runtime/results`，原日志副本保存在 `runtime/sources`，书签和备注保存在 `runtime/evidence`。报告管理中的删除操作清理所选报告、本机标注及闲置副本，用户导入的原文件保留在原位置。标注清理失败时会显示提示，可点击重试清理。

升级时先退出软件，用新版 `XidLens.exe` 替换原文件，保留同目录的 `runtime` 文件夹。

单次上传最多 512 MiB。压缩输入的成员、总读取量和事件数有限额，超限会提示读取不完整。

**在线更新**：默认每天在后台检查版本，发现新版时可选择下载更新、暂不更新（延后一天）或不再提醒此版本。软件更新中可分别关闭检查与提醒，设置会持续生效。下载完成后点击重启并更新，报告与规则会保留。

**官方规则**：在解析规则中检查 NVIDIA 官方英文表，确认后更新规则。新规则用于新导入和重新解析的报告。

**Xid 查询与排查手册**：搜索中文 Xid 说明或按问题查看排查步骤。各页的版本与更新显示当前版本和来源，支持分别更新资料；更新成功后替换原内容。
