# 使用说明

启动后点击“导入日志”，可一次选择多份文件。顶部下拉框切换报告，各报告独立保存。

**设备信息**：查看服务器 SN 与所有 GPU，按 SN / PCI 地址搜索。“查看来源”保留原始行；“复制到 Excel”使用制表符分列。

**错误记录**：选择 GPU 或全部记录，点击错误查看原文。100 行一页；记录行数不等于独立故障次数。“官方手册”直接打开 NVIDIA 原版。

**PCIe 拓扑**：按 NUMA 分组显示可关联的路径。只使用明确的桥 secondary bus 字段，不按地址大小猜连接。

**槽位参考**：lspci Physical Slot 与 dmidecode Type 9 Bus Address 匹配结果分别保留。模组机或复杂底板仍需结合 SN 和设备标签定位。

**导出**：设备清单为 TSV，Excel 可打开；日志摘要为 TXT；完整证据为 JSON。

点击右上角“退出”停止程序。结果在 `runtime/results`，退出后可删除其中的 JSON 清空历史。

单次上传最多 512 MiB。压缩输入的成员、总读取量和事件数有限额，超限会提示读取不完整。
