# 使用说明

启动后点击导入日志，可一次选择多份文件。顶部下拉框切换报告，各报告独立保存于本机 `runtime` 目录。

- **设备状态**：查看服务器 SN、机型、驱动版本及 GPU 清单，支持按 SN、UUID、PCI 地址搜索及切换「仅异常」。选中设备后在右侧查看设备信息与状态检查（PCIe 链路、未纠 ECC、行重映射等），点击行号可在原文抽屉中定位。点击「复制到 Excel」按列复制设备清单。
- **错误记录**：支持「按类型聚合」与「按时间顺序」两种视图，可按设备筛选。右侧展示原始日志，并严格按 NVIDIA 官方 Xid Catalog 提供中英双语说明、即时操作与调查操作，可直达对应排查手册章节或完整 Xid 目录。
- **机器拓扑**：
  - **PCIe 连接树**：展示由 `lspci -t`、`lspci -Dnnvv` 或 `sysfs` 建立的 PCIe 桥与设备层级。
  - **互联矩阵**：当日志包含 `nvidia-smi topo -m` 时展示实测矩阵；对于一般不含 `topo -m` 的 `nvidia-bug-report.sh` 日志，自动基于 `lspci` 桥结构与 NUMA 节点推导 PCIe 互联矩阵（等效 `topo -mp`，展示 `PIX / PXB / PHB / NODE / SYS`，不含 NVLink），支持切换 `GPU ↔ GPU` 与 `GPU ↔ 网卡`，右侧展示路径层级与公共上游分叉图。
- **日志对比**：在两份报告间按唯一 SN 或 UUID 匹配 GPU，默认仅显示变化项，点击「对比两侧原文」可并排核对原始日志。
- **原文抽屉与完整日志**：点击分析结果中的行号，打开原文抽屉。点击「完整日志」可在阅读器中继续查看同一行，支持 `Ctrl+F` 搜索、`Ctrl+G` 跳转、自动换行和异常定位。
- **Xid 目录与排查手册**：左侧可直接浏览或按 `Ctrl+K` 快速搜索官方 Xid Catalog（含中英切换、Xid 144–150 解码表、关联 Xid 154）与基于 NVIDIA GPU Debug Guidelines 整理的排查手册；「GPU 节点分流流程」内置中英双语交互式流程图（图 1～图 3），支持放大查看及点击节点直达对应章节。
- **软件与资料更新**：左下角「软件更新」提供统一的「检查更新」按钮。检查后可分别更新软件、NVIDIA Xid 解析规则、Xid 目录中文资料和 GPU 排查手册。软件自动检查可关闭。
- **导出**：顶部「导出」支持设备清单（TSV）、排障摘要（TXT）与完整记录（JSON）。
